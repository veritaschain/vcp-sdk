# Security

Report vulnerabilities privately through GitHub's "Report a vulnerability"
(Security tab of this repository), or by email to standards@veritaschain.org
with "vcp-sdk security" in the subject. Please do not open a public issue for
an unfixed vulnerability.

Private vulnerability reporting must be enabled in the repository settings for
the first route to be available; until it is, use the email address.

Scope notes: this is pre-release software. It verifies records offline and
does not establish key ownership or contact anchor services (see README.md,
"What it does not do"). A result of INDETERMINATE is not a pass.
