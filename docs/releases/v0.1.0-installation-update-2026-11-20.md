First release of an offline core for VeritasChain Protocol (VCP) v1.2.0 (vcp-spec tag `v1.2.0`, commit `b23acb2`), in Python, TypeScript and MQL5.

**First-party, pre-release, not certified.** Written by VeritasChain Co., Ltd., which operates the VeritasChain Standards Organization (VSO). It is not an external or independent implementation and does not change VSO's disclosed count of external implementations (zero). A `VALID` result means the checks the verifier ran matched; it is not a conformance claim.

* Canonical hashing: RFC 8785, with integers written as exact digits (INTERPRETATIONS.md I-4)
* RFC 6962 / RFC 9162 Merkle trees, inclusion and consistency proofs
* Ed25519 event and Merkle-root signatures
* Three-valued verification (VALID / INVALID / INDETERMINATE) for events, batches, chains and inclusion proofs
* `vcp` command line, including `vcp seal` for signing events written by MetaTrader 5
* MQL5 writer and example EA: **not compiled in CI**; run `VCP_SelfTest.mq5` in MetaTrader 5 before use

Install from this repository only; the packages are not published to PyPI or npm:

```
pip install "git+https://github.com/veritaschain/vcp-sdk.git@v0.1.0#subdirectory=python"
```

Read INTERPRETATIONS.md before comparing hashes with another implementation. CHANGELOG.md lists the changes made after three rounds of pre-publication review, commissioned by VeritasChain Co., Ltd. and carried out by an AI assistant (not an independent review).
